# To-Do App

A minimal to-do list web app built with plain HTML, CSS, and vanilla JavaScript — no frameworks and no build step. Type a task, click "Add" (or press Enter) to put it on the list, and click any task to toggle it as done (shown with a strikethrough). Tasks are saved to the browser's localStorage, so they survive a page refresh. To use it, just open `index.html` in any browser.
